# AGENTS.md

All repository text, code, comments, commit messages, issues, and PRs are in
English. Priorities: security > correctness > simplicity > speed of delivery.

`pohunekd/plugin-assistant` is the context package `pohunek.context.assistant`:
the assistant knowledge bundle of `zajca/pohunek`. It carries data only; the
launch logic stays in the core repository (`crates/assistant`).

- `package/bundle/` is generated by `scripts/assemble-bundle` from a pohunek
  checkout. Never edit it by hand; change `docs/knowledge/` in the core
  repository and assemble again.
- No credentials, no real model, ever.
- The version in `package/runtime.toml` follows the pohunek release of the
  checkout the bundle was assembled from.
